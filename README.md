# Imagette · SAR océan

Appli d'apprentissage (SAR océan, vagues, pluie, scattering et séparation de composantes), installable sur iPhone comme une application.

Installation : ouvrir l'adresse GitHub Pages dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
Fonctionne hors ligne ; la progression est enregistrée sur l'appareil.
